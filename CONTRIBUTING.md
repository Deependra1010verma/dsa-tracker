Contributing to DSA Tracker

Thank you for your interest in contributing to DSA Tracker!

DSA Tracker is an open-source project designed to help developers organize their DSA practice and revision schedules.

How to Contribute

Contributions are welcome in the following areas:

- Bug fixes and performance improvements
- UI/UX improvements
- Documentation updates
- New features for DSA tracking
- Testing and code quality improvements

Getting Started

1. Fork the repository.

2. Clone your fork:
   
   "git clone https://github.com/YOUR_USERNAME/dsa-tracker.git"

3. Navigate to the project:
   
   "cd dsa-tracker"

4. Install dependencies:
   
   "npm install"

5. Configure your environment variables using ".env.example".

6. Start the development server:
   
   "npm run dev"

Making Changes

1. Create a new branch for your changes.
2. Write clean, maintainable code.
3. Test your changes locally.
4. Commit with a descriptive message.
5. Push your branch to GitHub.
6. Open a pull request against the "master" branch.

Pull Request Guidelines

- Clearly describe your changes.
- Reference related issues when applicable.
- Include screenshots for UI changes.
- Avoid unrelated modifications.
- Never commit API keys, passwords, or other secrets.

Reporting Bugs

When reporting a bug, please include:

- A clear description of the issue
- Steps to reproduce
- Expected and actual behavior
- Screenshots or error logs, if relevant

Code of Conduct

Be respectful and constructive when communicating with other contributors.
